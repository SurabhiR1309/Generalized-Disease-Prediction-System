# Generalized Disease Prediction System

The Generalized Disease Prediction System is an AI/ML-powered healthcare platform developed to assist users in identifying potential health risks using medical and blood report parameters. The system predicts the likelihood of diseases such as diabetes, heart disease, and liver disease through trained machine learning models and provides users with personalized healthcare guidance.

Users can input medical parameters and blood report values into the platform, after which the system analyzes the data and generates predictions indicating possible disease risks. Based on the prediction results, the platform also recommends suitable doctors by displaying their specialization, consultation fees, city, and years of experience, helping users take further medical consultation efficiently.

The project aims to make preliminary health assessment more accessible, informative, and user-friendly while demonstrating the application of machine learning in healthcare analytics and decision support systems.

## Features
* Disease prediction using ML models.
* Supports diabetes, heart disease, and liver disease prediction.
* Blood report and medical parameter analysis.
* Doctor recommendation system.
* Displays consultation fees, city, and experience.
* Interactive and user-friendly interface.
